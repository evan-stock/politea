# 폴리티커 카드뉴스(캐러셀) 제작법 (2026-10-24, 11-01 수정)

저장소: github.com/evan-stock/politea (main). 원고 형식·명령은 저장소 `README.md`, 텔레그램 채널 소재는 `JJIRASI.md`를 먼저 읽고 따른다. 채널 방향·금지선은 프로젝트 문서 `채널_기본정보.md`가 이 스킬보다 우선한다. Claude API는 쓰지 않는다(채팅 원고 모드만).

## 채널 한 줄
우파(자유·시장·안보) 관점의 2030용 '정치 한 잔'. 주장은 분명하게, 근거는 확실하게. 중립·"팩트만"을 표방하지 않지만 사실과 다른 말은 쓰지 않는다.

## 1. 표지 사진 규칙 (사용자 결정 2026-10-24, 최우선)
- **표지(images[0])는 무조건 관련 정치인의 실제 사진.** 관련 정치인 = 소재의 주인공(발언자·논란 당사자), 여럿이면 핵심 1명.
- 쓸 수 있는 것: 보도사진, 대통령실·정책브리핑(korea.kr)·국회·정당 공식 사진, 의원 본인 SNS 사진, 영상 속 그 정치인 얼굴 장면.
- **표지로 쓰면 안 되는 것:** 캡처 화면(커뮤니티·SNS·기사 캡처), 여론조사·통계 그래픽, 텔레그램 후보 이미지(tgNN), 합성·AI 이미지. 이런 이미지는 안쪽 장(2번째 장부터)에만 쓴다.
- 얼굴이 크고 또렷한 사진, 소재와 같은 시기·같은 자리 사진 우선. 글자·로고가 크게 박힌 사진은 피한다. 일부러 우스꽝스러운 표정만 골라 외모를 조롱하지 않는다.
- 정치인이 없는 소재(사건·사회)는 현장 실제 사진·영상 장면으로 표지. 이때도 캡처 화면은 표지 금지.
- 사진 구하는 법: 원고에 `image_pages`(사진 많은 기사·korea.kr·국회 페이지 2~4개) + `"mode":"collect"` push → `manual: render` 커밋 뒤 `media/<id>/candidates.jpg`를 직접 보고 그 정치인이 또렷한 `pressNN`을 고른다(collect는 tg 이미지를 지우지 않음). 사진 주소를 바로 넣어도 된다(`"https://…jpg"`).
- `photo_credits`에 표지 사진의 언론사·기관을 넣는다.
- 렌더러는 텔레그램 소재(id에 `-jj`) 원고의 표지가 tg 이미지면 렌더를 멈춘다. 적당한 사진이 정말 없으면 그 소재를 버린다.

## 2. 표지 문구
- 2줄, 줄당 12자 안팎, 핵심어 하나를 `'작은따옴표'`로 강조(보라 띠).
- 질문·대비형을 기본으로: "A인데 B?", "~했더니 ~났다", "~ 총정리", "그럼 ~은요?", 발언 인용 "\"…\"" + 결과 한 줄.
- 후보 10개를 먼저 뽑고(전략 이름 표시) 하나를 고른다. 오늘의쓸모 `today-worthy-cover-hook`의 템플릿(진짜 이유형·알고 보니형·그 후형 등)을 정치 소재에 맞게 응용해도 된다.
- 숫자·발언은 기사로 확인한 것만. 확인 안 된 부분은 "~라는 주장", "의혹".
- 피드 예시: "오세훈 2심 무죄 뜨자 / '사실상 오세훈 대통령'", "집값 잡겠다고 묶었더니 / '전세'만 반토막 났다".

## 3. 장 구성 (README 형식)
- 0번 표지 → 안쪽 3~8장 → 마지막 CTA(글 비우면 기본 문구).
- 안쪽 장: `sub`(흰 박스 소제목) → `t`(색 헤드라인) → `b`(본문 2~4문장).
- 한 장 이상은 '반대 측 입장'을 공정하게 한 줄 이상 넣는다.
- 생활 연결 각도(월급·월세·청약·세금·군복무)를 한 장 넣으면 좋다. 정치에 관심 없는 사람도 '내 일'로 느껴 공유가 붙는다.
- 참고(2026-11-01 확인): 인스타는 2024년 2월 비팔로워 정치 콘텐츠 추천을 기본 '제한'으로 했다가 2025년 1월 한국 포함 전 세계에서 되돌렸다(기본 '표준', 이용자가 적게·표준·많이 선택). 정치 소재라서 비팔로워 노출이 일괄적으로 막히지는 않는다. 다만 개인화라 반응이 약하면 덜 보일 수 있으니 실제 비팔로워 비율로 확인한다.

## 4. 출처·캡션
- 카드·캡션 모두 출처 표기. `sources`에 언론사·날짜·주소.
- **'텔레그램'·'제보'·t.me 링크는 caption·credit·photo_credits·sources에 절대 쓰지 않는다**(2026-10-21 결정). 텔레그램 글 번호는 `risk`에만.
- 캡션: `[제목]` → 2~4문장 → 생각 묻는 질문 1줄 → 팔로우 유도 1줄. 해시태그 5개 이하.

## 5. 금지선
- 실존 정치인 합성·딥페이크·AI 얼굴 금지. AI 이미지는 실존 인물이 없는 상징 장면에만.
- 확인 안 된 실존 인물 소문(범죄·질병·사생활) 금지.
- 일반인 얼굴·이름·번호판은 가리고 조롱하지 않는다. 외모·장애 비하 금지. 놀리는 대상은 공인의 언행.
- 이미 올렸거나 승인 대기 중인 소재(state/posts 최근 7일)와 겹치면 안 만든다.

## 6. 보내기
- 확인 후 `"mode":"send"`로 `drafts/current.json` push → 렌더 → 텔레그램 미리보기 ✅/❌ → 승인 시 `publish_at`(기본 lunch 12:30, evening 21:00)에 게시. 미승인 3시간 뒤 만료.
- 보내기 전 점검: 표지가 정치인 실제 사진인가 / 숫자·발언이 기사와 같은가 / 텔레그램 표기가 없는가 / 반대 측 한 줄이 있는가.
