# 폴리티커 릴스 제작법 (2026-10-24)

저장소 github.com/evan-stock/politea의 `README.md`(릴스 원고 형식)와 `JJIRASI.md`(텔레그램 소재)를 먼저 읽는다. 프로젝트 문서 `채널_기본정보.md`의 '릴스 소재 우선순위'가 이 스킬보다 우선한다.

## 1. 소재 우선순위
반드시 실제 영상이 있어야 한다(사진·문자뿐이면 캐러셀로 → politea-cardnews).
1. 웃긴 정치 영상(최우선): 국감·회의·현장의 황당·민망·내로남불 장면, 말실수, 보여주기 퍼포먼스. 우파 관점으로 비꼬는 제목.
2. 사회·사건 실제 영상(치안·법집행 각도)
3. 정치인 발언 클립(분노형)
4. 정책 설명

## 2. 커버 규칙 (사용자 결정 2026-10-24)
- **커버는 관련 정치인의 실제 얼굴이 보여야 한다.** 캡처 화면·그래픽·텔레그램 이미지를 커버로 쓰지 않는다.
- 영상에 그 정치인 얼굴이 또렷한 장면이 있으면 `video.frame`을 그 시각(초, start 기준)으로 맞춘다.
- 영상이 캡처 화면·자료 화면뿐이면 사진을 구해 원고 최상위에 `"cover_image": "pressNN"`(또는 사진 주소)를 넣는다 → 커버의 영상 자리에 그 사진이 들어간다. 사진 구하기는 `image_pages` + `"mode":"collect"` → `candidates.jpg` 확인.
- 쓸 수 있는 사진: 보도사진, 대통령실·정책브리핑·국회·정당 공식 사진, 의원 본인 SNS 사진. 합성·AI 금지. `photo_credits`에 출처.
- 정치인이 없는 사건 영상은 가장 상황이 잘 보이는 실제 장면 프레임을 커버로.

## 3. 원고
- 형식: 검정 9:16, 위 제목 2줄(핵심어 `'강조'` 연보라), 가운데 원본 영상, 아래 POLITEA.KR + 영상 출처.
- 제목은 2줄, 첫 2초에 무슨 장면인지 알게. 과장은 되지만 사실과 다른 말은 안 됨.
- `video`: `src`, `start`, `dur`(영상 길이와 60초 중 작은 값), `frame`, `audio`, 워터마크·자막 있으면 `crop`.
- 앞뒤를 잘라 정반대 뜻이 되는 편집 금지 — 필요하면 `note`(영상 아래 맥락 한 줄)로 앞 문장·해명을 남긴다.
- 웃음은 제목·자막·타이밍으로. 영상 자체를 바꾸지 않는다.

## 4. 출처·캡션
- `credit`은 원출처("영상: 국회 의사중계", "영상: ○○ 의원 인스타그램"). 모르면 "영상: 온라인 커뮤니티".
- **'텔레그램'·'제보'·t.me는 caption·credit·photo_credits·sources에 쓰지 않는다.** 텔레그램 글 번호는 `risk`에만.
- 캡션: `[제목]` → 무슨 장면인지 2~4문장 → 질문 1줄 → 팔로우 유도 1줄. 해시태그 5개 이하. 반대 측 해명이 있으면 한 줄.

## 5. 영상 받기
- 국회 의사중계 VOD·인스타·X는 `drafts/video.json` push로 바로 받기 가능. 유튜브는 `YT_COOKIES`로 시도, "not a bot" 실패면 사용자에게 폰 저장을 부탁(쿠키 갱신은 사용자가 직접).

## 6. 금지선
- 실존 정치인 합성·딥페이크·AI 음성 금지. 일반인 얼굴 모자이크, 일반인 조롱 금지, 외모·장애 비하 금지. 잔인·성적 장면 금지. 확인 안 된 소문 금지.
- 남의 영상 그대로 재업로드 금지 — 제목·출처·맥락을 붙인 해설형으로.
- 최근 7일 이미 올린 소재(state/posts)와 겹치면 만들지 않는다.

## 7. 보내기
`"format":"reel"`, `"mode":"send"`로 `drafts/current.json` push → 렌더 → 텔레그램 ✅ 승인 후 게시. 보내기 전 점검: 커버에 정치인 얼굴이 보이나 / 텔레그램 표기 없나 / 맥락 한 줄 필요 없나.
